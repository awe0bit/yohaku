# 静置彩蛋：纸化回纸浆 — 设计

日期：2026-11-01 · 状态：已确认（2026-11-01）

## 1. 意图

读者在一个页面上长时间不动时，背景接管整个屏幕：所有可读内容（正文、页头、页脚、纸卡片、配图）化进水里，整张纸慢慢变回纸槽里的纸浆。纸浆里能玩：搅水、落滴、和当季花叶互动。任何明确的离开动作都把纸「澄清」回来，文字套色复印回原位。

它是 Yohaku 纸张背景（[[2026-10-17-paper-background-design.md]]）的延伸：背景本来就是照着手工和纸的材料做的（楮纤维、漉き込み、砂子、花入り、ぼかし），彩蛋让这些层在纸浆状态下各自动起来。季节限定感来自背景已有的节气花叶，而不是另外加的东西。

## 2. 目标 / 非目标 / 反目标

**目标**
- 只在支持 HTML-in-Canvas 的浏览器触发；用 HTML-in-Canvas 截取当前可见页面作为「墨」。**受众是手动打开 `chrome://flags/#canvas-draw-element` 的浏览器**：不注册 origin trial token，不加 OT meta/header。
- 进入、沉浸、退出三段都流畅，交互作用在背景已有元素上，季节不同玩法内容不同。
- 不影响普通浏览：未触发时零额外成本（不建 GL 上下文，只有一个空闲计时器）。

**非目标**
- 移动端、触屏设备、关闭背景效果、`prefers-reduced-motion: reduce` 时一律不出彩蛋。
- 不需要无 HTML-in-Canvas 的降级方案（用户明确：没有这个 API 就不做）。
- 不需要可访问性层面的等价体验；彩蛋是装饰，任何键盘操作立即退出。

**反目标（做出来但等于失败）**
- 字一进水就糊成灰团、看不出曾经是字。字必须保持笔画，被水流拉成墨流し的丝。
- GPU 跑满、交互卡顿。
- 回到正文后页面状态被破坏（滚动位置、React 状态、输入焦点、播放中的媒体）。
- 以下已被否决，不得回来：叶拓/拓印、七十二候钤印、活字、泡水（湿纸洇染）、退出时从下往上扫的抄纸帘边、大而规整的涟漪。

## 3. 体验时间线（已定）

| 阶段 | 时长 | 发生什么 |
|---|---|---|
| 阅读 | — | 计时器累计静置时间；任何 pointermove(>2px)、wheel、scroll、keydown、pointerdown、touch、focus 变化都清零 |
| 触发 | 静置满阈值 | 截取页面 → 隐藏真实内容 → 同时开始「还原图层」和「化回纸浆」，中间不停顿 |
| 还原图层 | 前 3.2s | 不论当前页面状态（browse/read/immersive），背景各层错峰回到 browse 档全满：纸色 0–1.2s → 纤维 0.3–1.7s → 砂子 0.8–2.2s / 漉き込み 0.9–2.3s → ぼかし 1.2–2.6s → 花叶 1.6–3.2s → 微动与闪光 2.2–3.2s |
| 化回纸浆 | 默认 22s | 0–10% 清晰文字淡入墨层；从 20% 起水流开始把墨带走（文字一开始只是被推得歪斜错开，后段被拉成丝）；12–82% 纸浆乳白浑浊层浮起；62–95% 花叶一片片浮上水面成为可交互实物 |
| 沉浸 | 不限 | 纸浆状态；交互见 §4；底部正中出现「回到正文」 |
| 退出 | 2.4s | 前 40%：纸浆原地澄清、花叶回到原位压回纸里、新落的花叶淡出；30%–100%：文字套色复印（先落 accent 再落墨，错版收拢） |

进入过程中（还原/化浆前段），鼠标累计移动 >60px、滚动或按键 → 取消：墨 0.6s 退回，背景回到原页面状态。化浆 >60% 后的离开动作走正式退出。

## 4. 沉浸态交互（已定）

- **划水**：鼠标轨迹往水里注入速度。墨被搅成墨流し；纤维、漉き込み、砂子、花叶按深浅随水位移（花叶最浅，纤维最深），停手后约 3s 沉回原位。
- **点一下**：落一滴，轮流「墨 → 清水 → 当季 accent 色 → 清水」。每滴是一个点源，把已有的墨推成同心年轮（真实墨流し做法）。点在可反应的花叶上则触发花叶反应，不落滴。
- **断续落叶**：每 2.2–6.4s（25% 概率连落两片）从上方落下一片当季花叶或花瓣（花取其花瓣形态 65%）。下落 2.4–3.8s：随高度放大、摆动、投影偏移并模糊，落水瞬间投影收拢，溅起 1–3 圈小涟漪（半径约 10–28px，圈数/间隔/寿命/扁度/倾角/浓淡全随机），并以很小的点源轻推周围的墨。
- **积多下沉**：落水后漂浮的花叶超过 14 片时最早的开始下沉；每片漂浮 35–65s 后也会下沉。下沉 4.8s：缩小、褪色、换成淡化版本、减速，最后消失。
- **季节限定**（只对当前节气在场的花叶生效）：
  - 春 · 梅/桃/樱/梨：水流急时（>520px/s）掉花瓣（每朵最多 5 片）；花瓣在静水里（<120px/s）彼此靠拢成花筏；花瓣与荷瓣顺流时长轴对着水流。
  - 夏 · 紫阳花：点一下，170px 内整簇色相 +70°（蓝 → 紫 → 粉，循环）；荷瓣像小船顺流。夏至、小暑、大暑：鼠标静止 >1.1s，萤从四周聚来绕鼠标飞，一动就散。
  - 秋 · 枫、银杏：急流（>260px/s）掀翻露出叶背（去饱和提亮版本）；点一片叶子它提前走一个节气（青枫 → 转色 → 红叶 → 枯叶；初黄 → 金黄 → 落叶），0.6s 交叉淡入；桂花被急流（>380px/s）散成小簇（最多 3 次），流动时拖一串金粉。
  - 冬 · 六花：鼠标 80px 内被「体温」化开（缩小、透明、留一圈水痕），移开后重新冻上；蜡梅：鼠标 110px 内被照透（加亮叠加 + 暖色光晕）。
- **退出入口**：底部正中「回到正文」按钮（化浆 30% 后淡入，静止 70% 不透明，悬停全显）；另外 wheel、任意键、Esc 都退出。

## 5. 约束

- **只用 HTML-in-Canvas**。特性检测 `'drawElementImage' in CanvasRenderingContext2D.prototype`。API 仍在变：Chrome 150 起属性是 `<canvas content="drawable">`，子元素需要 `drawable` 属性；更早版本是 `layoutsubtree`；Chrome 155 起 `drawElementImage` 不再返回 transform。实现时两种属性都设，返回值不依赖。参考 https://github.com/WICG/html-in-canvas 与 https://developer.chrome.com/blog/html-in-canvas-ot-changes 。
- **性能默认值（用户已在演示里调过）**：纸张背景渲染倍率在**彩蛋期间** 1×（Retina 2× 会让 GPU 跑满；1× 用户确认流畅）；平时保持设备 dpr；彩蛋帧率 30fps；墨分辨率 = CSS 像素 1×；墨的平流用带夹取的 Catmull-Rom 采样；墨层输出在「字还清晰」阶段（化浆 <70% 与退出）用 devicePixelRatio，其余 1×；流体网格 96 列；花叶投影开。
- 文件 ≤ 500 行，React 组件 ≤ 300 行；零注释原则（只有反直觉的地方写）。
- 背景动效统一近临界阻尼、无回弹（见 `src/theme/motion.ts` 的约定，web 侧同理）。
- 遵循已有分层：`apps/web/src/components/ui/background/paper/`。

## 6. 架构（已定部分）

### 6.1 截取：克隆进可绘制画布

> 实现更新：彩蛋不再克隆页面。应用挂载时若支持 HTML-in-Canvas，`CanvasRoot` 把 `#root` 直接放进 `<canvas content="drawable">` 并逐次 paint 绘制；彩蛋从该画布取当前视口。代价：canvas 子树内 `position: fixed` 与文本选择失效，跨域 `<img>` 在快照里为空。下面的克隆方案是早期设计，保留作对照。

触发时不移动真实 DOM（避免 React 协调出错），而是：

1. 克隆 `#root`（`AppShell` 里包着整站内容的 `div#root`）为 `clone`，剔除其中的 `canvas`、`video`、`iframe`。
2. 建一个 `position:fixed; inset:0` 的 `<canvas content="drawable" layoutsubtree>`，内放一个 `drawable` 的视口大小容器（`overflow:hidden`），容器里放 `clone`，用 `translateY(-scrollY)` 对齐当前滚动位置。`drawable` 元素是其后代 fixed 定位的包含块，页头等 fixed 元素因此仍贴在视口上。
3. 等 `paint` 事件，`drawElementImage(container, 0, 0, W·dpr, H·dpr)` 画进该画布，再整张上传成墨纹理（不预乘 alpha，翻转 Y）。
4. 立刻移除画布与 `clone`。只需要这一张快照；退出时复印也用它。
   - **配图不进快照**：跨域 `<img>` 在 `drawElementImage` 里会被留空，而站内配图大多是外链。克隆里把所有 `img`/`picture` 换成同尺寸透明占位（`visibility:hidden`），快照里只有文字、卡片和页头。
   - **真实配图原地淡出**：真实 `#root` 隐藏时给其中的 `img` 单独 `visibility:visible`，在化浆 0–35% 用 opacity 渐隐（可带轻微下沉位移/模糊感），像沉进水里；退出复印阶段再淡回。
   - **卡片和页头底色**：在克隆上把纸卡片、页头的不透明底色降到约 30% 不透明（演示里 `capture()` 的 0.3），让它们化成淡墨而不是整块。
5. 1.5s 内没收到 `paint` → 放弃本次触发，不出彩蛋。
7. **`#root` 之外的浮层**：`FABContainer`、`ReadIndicator`、`Presence`、`TtsFloatingPlayer`、`CommentBlockGutter` 弹层、toast 等经 `RootPortal` 挂在 `body` 上，不在快照里。彩蛋期间把它们统一 0.6s 淡出（opacity 0、不可点），退出复印结束后淡回；背景画布与彩蛋自己的图层除外。（我的决定）
6. 页面背景色在 `html/body` 上，不在 `#root`，所以快照是透明底的墨；纸卡片、页头的底色会作为整块「淡墨」一起化掉（在快照里以 0.3 不透明度处理，见演示 `capture()`）。

真实内容在截取成功后用 `visibility:hidden` 隐藏（保留布局与滚动位置），彩蛋结束恢复。滚动在彩蛋期间被 `wheel` 的 `preventDefault` 拦下。

### 6.2 背景接入（改 PaperBackground）

- **渲染倍率（仅彩蛋期间 1×）**：给 `PaperRenderer` 加一条只改尺寸的快速路径（如 `setRenderScale(k)`）：只改 `canvas.width/height` 与 `this.dpr`，**不**重建纤维和季节纹理（这些纹理按 CSS 尺寸生成，与 dpr 无关）。触发时切到 1×，退出动画结束后切回 `min(2, devicePixelRatio)`。`rebuild()` 走的是全量重建，进出彩蛋时调用会卡顿，不能用。演示 bench 里的 `setRenderScale` 就是这个做法。
- **页面状态覆盖**：新增「彩蛋覆盖」输入（jotai atom，如 `paperEggAtom`）。彩蛋活跃时目标 profile 用 `PAGE_PROFILES.browse`；还原阶段按 §3 的错峰表直接写 profile（不用 `SETTLE_TAU` 的指数逼近）；化浆中再额外写 `vis.sheet = 1 - ease(sink)`、`vis.dye = min(vis.dye, 1 - ease(sink))`、`vis.elem = min(vis.elem, 1 - lift(sink))`；退出时 `sheet`、`elem` 随澄清进度回到 1。
- **水流位移**：着色器新增 `tFlow`（RG8，GX×GY，`(D/120+0.5)` 编码 ±60px 位移）与 `uFlowOn`；在 `press()`/点击位移旁边加 `+= (texture(tFlow, uv).rg - 0.5) * 120 * uFlowOn`，让纤维（×0.6）、漉き込み（×1.2）、花叶（×1）按现有的位移系数产生视差。彩蛋每帧上传。
- **花叶实物化**：复用 `layout.ts` 的 `layoutElements(w, h, term)` 拿到 `ElementPlacement[]`，用 `paintElements` 逐片画成小精灵图；与纸里的花叶同位、同角度、同翻面，浮起时交叉替换（纸里的 `vis.elem` 降、精灵升）。
- 正在节气过渡（`renderer` 的 transition）时触发：以目标节气的布局为准。

### 6.3 彩蛋模块（新目录 `background/paper/egg/`）

| 文件（建议） | 职责 |
|---|---|
| `idle.ts` | 静置计时、取消条件、事件监听；纯逻辑可测 |
| `phase.ts` | 状态机 reading → sinking → immersed → exiting / 取消回退；时间曲线（还原错峰、化浆分段、退出分段）；纯函数可测 |
| `capture.ts` | §6.1 的 HTML-in-Canvas 克隆截取 + 特性检测 |
| `fluid.ts` | CPU 稳定流体（96 列网格、半拉格朗日平流、18 次 Jacobi 投影、阻尼 e^(-0.55t)、边界零速度）、鼠标注入、点源落滴、位移场；速度编码 |
| `ink-gl.ts` | 墨的 GL 管线：COPY（快照→墨）、ADVECT（平流 + 落滴点源 + 色滴/清水滴 + 稀释）、SHOW（纸浆乳白层 + 墨 + 清晰文字淡入 + 套色复印）；双 FBO 乒乓 |
| `sprites.ts` | 花叶精灵：生成（正面/叶背/投影三张预渲染）、物理、季节反应、绘制 |
| `falls.ts` | 断续落叶、涟漪、上限与下沉 |
| `fireflies.ts` | 萤 |
| `PaperEgg.tsx` | 挂载与生命周期：条件满足才建 GL 上下文；30fps 节流 rAF；退出按钮；i18n |

关键数值全部照演示（`docs/superpowers/specs/assets/2026-11-01-idle-pulp-egg-demo.html` 里第二个 `<script>`，即彩蛋脚本），包括：
- **速度编码必须用平方根压扩**：`e = sign(v)·sqrt(|v|/1500)`，存 `round(128 + e·127)`；解码 `e = (t·255−128)/127`，`v = sign(e)·e²·1500`。旧的线性 `(v/3000+0.5)` 会把零速度读成约 6px/s 的漂移，墨每帧重采样，字被抹糊——这是演示里踩过的坑。
- 平流采样用 5 次读取的 Catmull-Rom，结果夹在 4 个最近纹素的 min/max 之间。
- 稀释：概率性每帧减 1/255（`hash < uDecay`），30fps 下化浆期 `uDecay = (1 − 墨留量)·0.5·ease((s−0.2)/0.7)`，沉浸期 `(1 − 墨留量)·0.05`；墨留量默认 0.6。扩散：化浆期 `0.002 + 0.03·ease((s−0.35)/0.6)`，沉浸期 0.014。
- 环境暗流：化浆期 `26·ease((s−0.2)/0.6)` px/s²，沉浸期 10。
- 纸浆乳白层：浅色 `(0.975,0.968,0.948)`，深色 `(0.34,0.33,0.315)` 且不透明度 ×0.42；墨在深色主题显示不透明度 ×0.6。
- 边界：平流回溯点出界时取空（不夹边），否则边缘会凭空长出墨。

### 6.4 触发条件（全部满足）

桌面（非 `useIsMobile`）、背景效果开启、`PaperBackground` 已就绪且可见、非 reduced motion、`document.visibilityState === 'visible'`、HTML-in-Canvas 可用、页面没有打开的弹层/模态/搜索面板、没有正在播放的媒体（`<audio>`/`<video>` 未暂停、`BgmProvider` 未播放）、静置满阈值。

### 6.5 强制结束（不走动画，立即恢复）

路由变化、主题切换、窗口尺寸变化、页面隐藏、WebGL 上下文丢失、背景被关闭。

### 6.6 i18n

`common.json` 五种语言新增退出按钮文案：zh「回到正文」、zh-TW「回到正文」、en「Back to the page」、ja「本文に戻る」、ko「본문으로 돌아가기」。

## 7. 交给实现者的

- 文件的具体拆分、模块间接口形状。
- 克隆截取时 `clone` 里需额外剔除/修正的元素（例如 `position: sticky` 的处理）——以截图与真实页面一致为准。
- **第一步先做截取验证**：演示的最终版在无 API 时走的是逐字光栅，HTML-in-Canvas 截取只在最早一版演示里于 headless Chrome 跑通过（单篇文章）。实现前先在打开 flag 的 Chrome 里对真实站点验证：固定页头是否贴视口、字形是否与原页一致、卡片底色降透明是否生效、`paint` 事件耗时。不通过再回来讨论。
- 测试取舍：`phase.ts`、`idle.ts`、速度编解码、季节反应映射写单测（vitest，仿照 `paper/*.test.ts`）；GL 与截取靠在支持的 Chrome 里实际跑。
- 精灵画布的 dpr 上限、落叶投影的预渲染尺寸。

## 8. 我替用户做的决定

- **静置阈值 60s**（演示用 8s 方便看；线上需要「长时间停留」）。
- 触发条件里加了「无弹层、无播放中媒体、页面可见」。
- 截取用克隆而不是移动真实 DOM。
- `#root` 之外的浮层在彩蛋期间统一淡出（§6.1 第 7 条）。
- 强制结束的情形（§6.5）。
- 退出按钮的四种外语文案。
- 演示面板里的调参项（墨留量、划水力度、纸层漂移等）线上不暴露，取演示默认值。
