# TL;DR · 静置彩蛋：纸化回纸浆

完整设计：`2026-11-01-idle-pulp-easter-egg-design.md`

## 做什么

把演示页里的纸浆彩蛋做进网站。彩蛋期间纸张背景临时降到 1× 渲染。

## 你会看到

1. 在任意页面静置 60 秒（只限桌面、背景开着、Chrome 打开了 `chrome://flags/#canvas-draw-element`）。
2. 背景各层错峰回到全满，同时文字和卡片化进水里、配图原地淡出，约 22 秒变成一槽乳白纸浆，花叶浮上水面。右下角按钮等浮层同时淡出。
3. 划水搅出墨流し；点一下落墨、清水或当季色；当季花叶断续落水、溅起小涟漪，积多了沉下去。
4. 季节限定：春天掉花瓣成花筏，夏天紫阳花转色、萤，秋天叶子翻面、提前转色，冬天六花化开、蜡梅透光。
5. 点底部「回到正文」或滚动、按键：纸浆澄清，文字套色复印回来，滚动位置不变。

## 已定

| 项 | 决定 |
|---|---|
| 截取 | HTML-in-Canvas；不支持就不出彩蛋；只给开了 flag 的浏览器，不注册 token |
| 配图 | 外链图进不了截图，真实配图原地淡出 |
| 截取方式 | 克隆整站内容进可绘制画布，截一张就移除，不动真实 DOM |
| 进入 | 还原图层与化浆同时开始，化浆 22s |
| 退出 | 显式按钮 + 滚轮/按键；原地澄清，无帘子 |
| 涟漪 | 小（10–28px）、1–3 圈、全随机 |
| 性能 | 彩蛋期间纸背景 1×（平时不变）、彩蛋 30fps、墨 1× + 锐利采样 |
| 否决 | 印章、拓印、活字、泡水、帘子 |

## 请检查（我替你定的）

- 静置阈值 **60 秒**
- 有弹层、搜索面板、正在播放的音乐/视频时不触发
- 右下角按钮、阅读进度、Presence、TTS 播放器等浮层在彩蛋期间淡出
- 路由变化、换主题、改窗口大小、切走标签页时立即结束（不播动画）
- 退出按钮外语文案：Back to the page / 本文に戻る / 본문으로 돌아가기
- 演示面板里的调参项线上不暴露

## 时间

约 2.5–3 天：先在开 flag 的 Chrome 里验证真实页面截取（半天，不通过就回来讨论）；背景接入与 1× 快速切换半天；截取与墨的管线 1 天；花叶、落叶、季节反应 1 天；在 Chrome 里联调与收尾半天。
